# HAIO - Hide AI Overview

![Logo](./src/assets/logo128.png)

This browser extension lets you hide the AI Overlay within Google search results. The AI Overlay often spoils results of matches, or events within its responses. Or sometimes you just don't want any overview and just care about links. This extension hides the overview, and lets you toggle to show or hide it.

## Important Notice

Because the extension works by finding specific selectors and hiding it, this extension can break when Google changes its markup code. The OVERVIEW_SELECTORS value will need to be updated when that happens.

## Supported browsers and search engines

Currently it only supports Chrome and Google search. I will add Firefox support and support for other search engines (like DuckDuckGo) only if this somehow, magically, becomes some popular extension. Otherwise this remains as my short term side project.
